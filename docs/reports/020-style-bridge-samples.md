## 1. 한 일

**견본 셋** — 얼굴·비례·자리·배경·UI·신호 표시는 같고, 인물(상대·의뢰인·내 손)의 선·칠·그림자만 다릅니다.

| | A 깔끔한 사람 | B 잉크로 이은 사람 | C 판화로 기운 사람 |
|---|---|---|---|
| 선 | 고른 굵기의 검정에 가까운 선 | 굵기가 변하는 고동색 잉크 선, 조금 거친 가장자리 | B와 같다 |
| 칠 | 맑은 색 | 배경과 같은 바랜 팔레트 | 더 바랜 색, 칠 위에 옅은 종이 결 |
| 그림자 | 평평한 한 단계 | 평평한 한 단계 | 빗금(판화의 해칭) |

**장면 16개**:
- 결투(큰 베기의 예비 동작, 갓 올린 막기)

결투 장면은 지금 게임의 값 그대로 그렸습니다: 자세, 칠의 80% 섞임, 두 줄 상태 글자, 고리, 조준 테두리.

## 2. 확인한 것 / 못 한 것

**확인한 것**

- **굽기**: 22장(섹션 16 + 밝은 무대 6)을 모두 1280×720으로 구웠습니다. 한 장씩 차례로 띄우고 끝을 기다렸습니다. 끝난 뒤 우리 프로필로 뜬 Edge는 0개였습니다. 사용자의 Edge는 건드리지 않았습니다.
- **그린 뒤의 문서**(`--dump-dom`):
  - 섹션 16개를 셌습니다.
  - 파츠 여덟(`Legs`·`Torso`·`Head`·`Hat`·`Feather`·`Arm`·`Hand`·`Sword`)이 그림에서 30건씩입니다. 문서에서 센 31건 가운데 1건은 페이지 스크립트 안의 틀입니다.
  - 모자가 보이는 그림은 결투 셋뿐입니다. 조준 테두리는 6건(결투 셋·멀리 셋)입니다.
- **신호색**: 열여섯 값을 코드(`opponent_01.tres`, `opponent_view.gd`, `player_sword_view.gd`)와 견줬고 모두 같습니다.
- **칠의 섞임**: B의 빈틈 칸 몸통 세 점을 재었더니 `80,125,219`로, 게임의 `lerp(#5C6F7E, #4D80F2, 0.8)`과 정확히 같습니다.
- **신호 구역**: 채도 55% 이상이면서 명도 85% 이상인 바탕·인물 색은 없습니다. A의 몸통 그림자색 하나가 채도 53%여서 45%로 고쳤습니다.
- **교전의 꼭대기**: 모자 꼭대기가 화면 y 149.4로, 두 줄 상태 글자(y 62~142) 밖입니다. 깃털 끝은 (769, 162)로 글자 상자 밖입니다.
- **바깥 자원**: `src`·`href`·`url(`의 웹 주소, `<img`·`<link`·`@import`·`fetch(`·`data:image`·`reference/` 모두 0건입니다.
- **참고 폴더**:

  - `git log -- docs/style/reference`는 비어 있습니다.

**확인 못 한 것**

- 다른 브라우저에서의 모습. 글꼴과 SVG 필터가 다르게 나올 수 있습니다. 보시는 모습이 기준입니다.
- 4단계의 제작 길에서 이 꼴이 그대로 되는지. Godot의 SVG 가져오기가 필터(거친 선, 종이 결)를 그리는지는 실행해 봐야 압니다.
- `.gdignore`가 듣는지. 021에서 참고 그림이 처음 들어온 뒤 playtester가 처음 돌린 다음에 `docs/style/**/*.import`가 0건인지로 확인합니다.
- 굽기 중에 Edge가 오류 줄 하나를 찍었습니다(Edge 자체의 동기화 기능, `ERR_ABORTED`). 견본과는 상관없습니다.

## 3. 설계와 다르게 구현한 부분

- **참고 폴더의 자리**: 처음 말씀드린 `assets/art/reference/` 대신 `docs/style/reference/`입니다.
- **상태 색을 칠에만 입혔다**: 지금 게임은 파츠 전체의 색을 바꿉니다. 일러스트로 바꿀 때 칠·선을 나눠야 같은 효과가 나므로, 4단계에서 정합니다.
- **밝은 무대의 잉크 테두리**: 지금 게임에 없는 제안입니다.
- **깃털을 옆으로 눕힌 꼴**: 지금 게임의 깃털은 둘째 줄 글자에 걸립니다. `docs/BACKLOG.md` 020-1에 남겼습니다.
- **내 손을 아래 안내 띠 위에 그렸다**: 게임은 띠가 손을 덮습니다. 손의 화풍을 보여 드리려는 것입니다.
- **견본은 상태 칸을 크기 0.55로 그렸다**: 교전은 0.85입니다. 칸 폭에 칼끝이 들어가게 하려는 것입니다.

## 4. 결정해 주실 것

견본 페이지를 열어 보시고 답해 주세요.

1. **셋 가운데 어느 쪽이 가까운가요?** A / B / C / 섞기. 축마다 골라도 됩니다.
   - 선: 고른 검정 / 굵기가 변하는 고동 잉크
   - 칠: 맑은 / 바랜 / 더 바랜, 종이 결
   - 그림자: 평평한 한 단계 / 빗금
2. **결투의 무대**: 짙은 무대 / 밝은 양피지 무대.
   - 짙은 무대: 신호가 지금처럼 또렷합니다. 고리 8:1, 찌르기 칠 5:1.
   - 밝은 무대: Potion Craft에 가깝습니다. 대신 고리에 잉크 테두리를 둘러야 하고, 예비 동작으로 물든 몸이 양피지에 거의 묻힙니다(찌르기 약 1.1:1). 찌르기·베기는 색상과 잉크 선으로만 읽게 됩니다.
3. **얼굴과 비례**: 지금 크기가 좋다 / 머리를 더 키운다 / 줄인다.
   - 상대의 머리는 교전 거리에서 두 줄 상태 글자를 가리지 않아야 합니다. 모자를 쓴 판은 지금 게임의 약 1.4배, 모자 없는 판은 약 2배까지입니다.
   - 견본은 약 1.33배입니다(78 → 104).
   - 의뢰인은 이 한계가 없습니다.
4. **싫은 것**이 있으면 한 줄로.

그 밖에:

5. 참고 스크린샷을 저장소에 올리지 않는 것, 폴더 자리(`docs/style/reference/`), 3단계를 020·021·022로 나눈 것.
6. **021 전에 여쭐 것**:
   - GPT 이미지 생성의 약관이 게임에 쓰는 것(상업 사용)을 허락하는지.
   - Codex를 어디에 쓸지.
7. 020의 커밋.

보류 중인 것(그대로 뒀습니다): 2단계의 값과 결정(`docs/HANDOFF.md` 3번), `docs/BACKLOG.md`의 기존 항목.
