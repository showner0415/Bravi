## 정해진 것 — 그림을 만드는 길 (결정 209)

인물 시험 아홉 장을 거쳐 사용자의 눈에 맞춘 길이다.

1. 섞은 SVG 견본을 **화풍의 참고 그림**으로 넣어 새로 그린다. 말만으로는 SVG의 꼴이 옮겨지지 않았다.
2. 꼴과 디테일의 양은 **섞은 SVG만큼 단순하게** 둔다. 올리는 것은 만듦새(비례, 이음매, 물건을 쥔 손)다.
3. 디테일은 **조금만** 더한다. 고른 그림을 바탕 그림으로 넣고 "실루엣은 그대로, 안쪽에 이것만"이라고 적으면 실루엣이 화소 단위로 지켜진다.
4. 전신 그림은 여유롭게 결투에 임하는 자세, 팔다리는 굽히지 않는다.
5. 선은 섞은 SVG의 굵기(5.0~5.6), 바지는 밝힌 색.

기준 그림(로컬 `docs/style/generated/`): `023-R1i-bartolo-front.png`, `023-R2-stage-alley.png`, `023-R3-client-clara.png`.

## 4. 사용자가 결정해야 할 것

1. **022·023의 커밋**: 둘 다 커밋 전이다. 지시하시면 커밋한다(생성 그림은 올라가지 않는다).
2. **다음 계획 024의 범위와 장 수 상한**: 파츠 시트(정면, 떨어진 팔. 여기서 상태 넷을 확인한다), 무대 둘(안뜰·광장), 비토리오, 기준 이미지 고르기와 `docs/style/basis/`로 올리기, 팔레트 확정. 023에서 상한 8로 11장을 썼으니 상한을 넉넉히 잡거나 "인물마다 몇 장"으로 정하는 편이 맞다.
3. **파츠 시트의 자세**: 게임의 상대는 팔·칼·머리를 따로 움직인다. 파츠 시트는 정면에 팔이 떨어진 배치여야 하는데, 전신 그림에서 고르신 "여유롭게 결투에 임하는 자세"는 게임 안에서 파츠의 놓임(대기 자세의 팔·칼 각도)으로 내야 한다. 024에서 그 대기 자세를 견본으로 보여 드리고 정한다.
4. **바르톨로의 성격**: 의뢰 대사에서는 허영심 많은 싸움꾼인데, 표정은 "거만하지 않고 여유로운" 쪽을 고르셨다(R1e의 자신 있는 미소). 그대로 두고 파츠 시트의 다른 표정(당황, 어지러움)에서 성격을 낼지 024에서 묻는다.
5. **임시 값 셋**(확정은 024): 바지 `#836850`("좋다"), 선 굵기(5.0~5.6 "좋다"), 무대 R2의 왼쪽 지붕이 면 전체가 기와로 그려진 것(그대로 둘지).
