## 1. 한 일

- **결투의 멈춤**(`scripts/duel/duel_scene.gd`): Esc를 누르거나 창 포커스를 잃으면 판의 시간과 상대 동작(예비 동작, 빈틈, 제한 시간, 엉킴, 방심)이 함께 멈춘다. 포커스가 돌아와도 저절로 풀리지 않는다.
- **"계속"의 클릭은 공격이 아니다**: "계속" 뒤 0.4초 동안 판은 멈춘 채 내 칼 위에 "다시 시작한다"가 뜨고, 그동안의 좌클릭은 버린다(막기·W·S는 받는다). 돌아오는 순간 막기를 우클릭 상태에 맞추고, 쥔 채 돌아와도 패리로 치지 않는다.
- **멈춤 화면**(`scripts/ui/pause_menu.gd`): 계속 · 설정(S01의 설정 화면) · 나가기. 하루 결투는 "처음 화면으로"와 그 아래 "이어서 하면 N일차 아침부터 시작한다 — 오늘 한 일은 남지 않는다", 연습은 "연습 고르기로". 카운터·정산·폐점에서 Esc를 누르면 같은 창이 "잠깐"으로 열린다 — 하루 중 어느 화면에서나 설정을 연다.
- **창 닫기**(`scripts/game_session.gd`, `scripts/ui/quit_confirm.gd`): 하루 중에 창의 X·Alt+F4로 닫으면 확인 창("게임을 끈다 · 끈다 / 돌아간다")이 돌아올 날을 알린다. 처음 화면·연습·저장된 폐점에서는 바로 끈다. 확인 창이 떠 있을 때 한 번 더 닫으면 바로 꺼진다.
- **처음 화면**(`scripts/title.gd`): 아래 줄이 도움말 · 설정 · 게임 종료 세 칸. 게임 종료는 확인 없이 끈다.
- **도움말**: "Esc 의뢰 선택" → "Esc 멈춤".
- **테스트·도구**: 새 T98·T99(`tests/pause_tests.gd`), UI 찍기 22장(멈춤·잠깐·확인 창·`pause-hold` 등), 헤짐이 글·버튼에 닿는지 세는 줄, 고리 겹침 측정 바로잡기, 창 도구(`tools/playtest-window.ps1`)의 `DoubleClick`·`FocusOut`/`FocusIn`(흉내)·`Quit`, `.claude/agents/playtester.md` 두 줄.

## 2. 직접 실행해서 확인한 것 / 확인 못 한 것

**확인한 것**

- 메인이 읽은 장: 하루 멈춤, `pause-hold`, 처음 화면, 창 닫기 확인.

**직접 해 봐 주세요 — 흉내가 아닌 진짜 창의 길**(playtester의 도구로는 낼 수 없다)
1. 결투 중 진짜 **Alt+Tab**으로 다른 창에 갔다 돌아온다: 멈춤 화면이 떠 있고 남은 시간이 같은가.
2. **우클릭을 쥔 채** Alt+Tab, 쥔 채 돌아와 Esc로 계속: 막기가 풀려 있는가 이어지는가(흉내에서는 풀려 있었다).
3. 결투 중 창의 **X 단추와 Alt+F4**: 확인 창이 뜨고 "돌아간다"로 판이 이어지는가.
4. 멈춤 화면의 "계속"을 **손으로 더블클릭**: 공격이 나가지 않는가, 그리고 "계속" 뒤 0.4초 대기가 답답하지 않은가.

## 3. 설계 문서와 다르게 구현한 부분과 이유

- **창 확인에서 찾은 버그**: 창 포커스를 잃으면 판은 멈추는데 멈춤 화면이 붙지 못해(알림이 도는 동안 노드를 붙일 수 없다) 판이 영영 멈췄다. 테스트는 알림을 직접 불러 이 길을 타지 않아 통과했었다. 멈춤을 미뤄 부르고, 붙지 않으면 멈춤을 되돌리고, 테스트가 실제 길을 타게 고쳤다.
- **고리 겹침 측정을 바로잡았다**(검토의 제안): 패턴 장의 겹침 줄이 33에서 0이 되었다 — 그동안의 겹침은 측정 셈의 잘못이었다.
- 첫 자동 확인에서 셋을 고쳤다: "게임 종료"가 126 폭에 안 들어 아래 줄 글자 20→18, 테스트가 "다시 시작한다" 라벨을 틀린 경로로 찾음, 처음 화면 버튼 수 기대 5→6.
- 카운터·정산·폐점의 "잠깐" 창을 함수 하나(`PauseMenu.open_for_day`)로 묶었다(계획에 없던 세부).
- 슬라이더 끌기는 창 도구에 끌기 동작이 없어 클릭으로 대신 봤다.
