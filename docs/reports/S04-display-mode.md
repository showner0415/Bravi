## 1. 한 일

- **화면 탭**(`scripts/ui/settings_screen.gd`): 설정에 "화면" 탭. 창 / 전체 화면(테두리 없음), 창 크기(1280×720·1600×900·1920×1080·2560×1440·3840×2160 가운데 모니터에 드는 것), "지금" 글과 F11 안내. 처음 화면과 멈춤 화면 어디서든 연다.
  - 고르면 곧바로 걸린다. 크기 버튼을 누르면 창으로 돌아가 그 크기로 모니터 가운데에 선다. 이미 눌린 버튼을 눌러도 다시 걸린다 — 전체 화면에서 빠져나오거나, 손으로 끈 창을 고른 크기로 되돌린다.
  - 모니터에 드는 크기가 하나도 없으면 드는 가장 큰 16:9 크기 하나로 열고 한 번 알린다.
- **F11**: 어디서나 전체 화면을 켜고 끈다. 흐르는 결투에서는 판을 먼저 멈춘다(전환의 검은 순간에 맞지 않게). 조작 탭에서는 쓸 수 없는 키가 됐다.
- **창**: 손으로 끌어 크기를 바꿀 수 있다. 그림은 늘 16:9이고 남는 곳은 검은 띠다. 끈 크기는 기억하지 않아 다시 켜면 고른 크기로 연다.
- **저장**(`scripts/display.gd`, `scripts/settings.gd`): 설정 파일의 `display` 갈래(영업 세이브와 따로). 화면을 바꾸지 않은 사람의 파일에는 적지 않는다.
- **테스트·찍기**: 테스트·찍기는 플레이어 설정에 전체 화면이 적혀 있어도 창을 건드리지 않는다(헤드리스이거나 테스트 경로로 띄우면 설정을 읽기 전에 잠근다). 새 T102·T103(`tests/display_tests.gd`), UI 찍기 25장(`settings-display`), 기존 기대 둘(T0의 F11, T75의 화면 탭). `tools/start-playtest.ps1`은 확인용 설정 파일로 띄운다.

**직접 해 봐 주세요**(Q1 — playtester를 부르지 않았다. 창 도구로는 진짜 모니터·전체 화면을 볼 수 없다)
1. 설정 → 화면에서 1600×900(들어가면 1920×1080): 창이 그 크기로 가운데에 서는가. 연습 결투에서 커서를 아홉 칸에 차례로 두면 조준 표시가 커서의 칸과 같은가. 결투 중 Esc → 설정 → 화면에서 크기를 바꾸고 "계속"한 뒤에도 맞는가. 창을 끌어 바꾼 뒤 눌린 크기 버튼을 누르면 돌아오는가.
2. 전체 화면: 테두리 없이 모니터를 덮는가. **가장자리에 1화소 줄이 보이는가**(Windows의 테두리 없는 전체 화면이 일부러 남기는 줄 — 거슬리면 알려 주세요. 대안은 배타 전체 화면이고 한 줄로 바뀐다. 대신 Alt+Tab마다 잠깐 검어질 수 있다). 전체 화면에서 눌린 크기 버튼을 누르면 그 크기의 창으로 돌아오는가.
3. F11을 처음 화면·카운터·결투 중·멈춤 화면에서: 바뀌는가, 결투 중에는 먼저 멈추는가, 카운터에서 초점 버튼이 눌리지 않는가.
4. 전체 화면이나 1600×900으로 두고 껐다 켜기: 그대로 열리는가, 켤 때 잠깐 창이 바뀌는 것이 거슬리지 않는가.
5. 창 가장자리를 끌어 길쭉하게: 검은 띠가 생기고 조준이 맞는가.
6. 모니터가 둘이면: 둘째 모니터로 옮긴 뒤 전체 화면이 그 모니터를 덮는가, 크기 목록이 그 모니터에 맞는가.
7. 전체 화면에서 Alt+Tab: S02의 멈춤이 그대로인가, 돌아오면 전체 화면 그대로인가.
8. 큰 모니터(크기가 넷·다섯 보이는 경우): 크기 버튼이 두 줄로 나뉘어 판 안에 드는가(찍기는 크기 셋인 본보기 모니터라 이 모습을 못 봤다).

S02의 넷, S03의 여섯도 아직 남아 있다.
