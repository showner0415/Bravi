## 1. 한 일

- **조작 탭**(`scripts/ui/settings_screen.gd`): 설정에 "조작" 탭. 공격·막기·전진·후퇴의 버튼을 누르고 쓸 키나 마우스 버튼(좌·우·가운데·옆 둘)을 누르면 바뀐다. "처음 값으로"가 넷을 되돌린다. 처음 화면과 결투·하루의 멈춤 화면 어디서든 연다.
  - 다른 동작의 키를 주면 받고 그 동작은 빈다 — "겹쳤다 — 막기: 좌클릭 · 공격은 이제 비었다", 빈 동작의 버튼은 붉은 "없음", 아래에 "비어 있는 동작: 공격 — 결투에서 쓸 수 없다"가 늘 뜬다. 막지는 않는다.
  - Esc·R·F1·Space·Enter는 받지 않는다("쓸 수 없는 키다 (R · 다시 하기)"). 휠도 받지 않는다.
  - 기다리는 중: Esc는 취소, 다른 버튼(닫기·탭·처음 값으로·다른 동작)을 누르면 취소되고 그 버튼이 평소대로 눌린다. 좌클릭은 그 칸이나 빈 곳에서 준다. 버튼을 두 번 누른 둘째 누름은 잡지 않는다.
- **저장**(`scripts/controls.gd`, `scripts/settings.gd`): 설정 파일의 `controls` 갈래(영업 세이브와 따로). 키는 자판의 물리 자리로 적는다. 깨진 값은 그 칸만 처음 값으로, 겹친 파일은 넷 모두 처음 값으로 읽고 조작 탭이 한 번 알린다.
- **결투·도움말**(`scripts/duel/duel_hud.gd`, `duel_scene.gd`, `scripts/title.gd`): 바꾼 키는 곧바로 결투에 걸린다(멈춤 화면에서 바꿔도). 도움말이 바뀐 키 이름을 쓰고 빈 자리는 "—", 첫 줄 끝에 "비어 있는 동작: …". 결투가 시작할 때 빈 동작이 있으면 기록 줄에 한 번. 엉킴·런지 안내의 말을 "물러난다(S)" 꼴로 고쳤다(키 이름 뒤 토씨 때문). "계속" 뒤 대기 중에는 왼쪽 버튼을 무엇에 묶였든 버린다.
- **테스트·찍기**: 새 T100·T101(`tests/controls_tests.gd`), 테스트·스모크·결투를 띄우는 찍기가 조작을 처음 값으로 두고 돈다(`run_tests.gd`, `ui_shots.gd`, `day_smoke.gd`, `pattern_shots.gd`, `stage_shots.gd`, `hand_shots.gd`), UI 찍기 24장(`settings-controls`, `settings-controls-empty`), 기존 기대 둘(T97, T75).

## 2. 직접 실행해서 확인한 것 / 확인 못 한 것

**확인한 것**
- verifier V1: `ALL PASS 101/101`(오류·경고 0), 스모크, 상대 57·UI 24·패턴 38, 화면 맞춤 그대로, 헤짐이 글에 닿는 곳 0, 고리 겹침 0. 사용자의 세이브·설정 파일은 전후 해시가 같다.
- verifier V1b: 키를 바꾼 설정 파일(공격 J, 막기 없음, 전진 Up, 후퇴 K)을 건 채로도 101/101, 스모크·찍기 통과, 로그에 빈 동작 알림 0줄 — 플레이어의 키가 테스트를 흔들지 않는다. 그 파일은 테스트가 적지 않았고, 메인이 적고 지웠다.
- T101: 겹치면 비우기, 조작 탭(실제 클릭 — 기다리는 중 다른 버튼은 취소되고 눌림, 같은 칸·빈 곳은 잡힘, 우클릭은 어디서나 잡힘), 바꾼 키가 실제 입력 길로 결투에 들어감, 멈춤에서 바꾸고 계속, 빈 막기의 대기, 도움말 글.
- 메인이 읽은 장: `%TEMP%\bravi-S03\after3\ui\settings-controls-empty.png`(조작 탭이 강조되고 "없음"·알림·경고가 판 안에 든다).

**직접 해 봐 주세요**(Q3 — playtester를 부르지 않았다)
1. 설정 → 조작에서 공격을 J로, 그다음 전진에 S를 준다: 후퇴가 "없음"이 되고 알림과 경고가 뜨는가. 도움말에 "J 공격", "S/— 간격"과 "비어 있는 동작: 후퇴"가 보이는가.
2. 연습 결투에서 J가 공격, 좌클릭은 아무 일 없음, S가 전진이고 후퇴는 안 되는가. 결투 시작의 기록 줄에 "비어 있는 동작: 후퇴"가 뜨는가.
3. 게임을 껐다 켜도 바꾼 키와 빈 후퇴가 남는가.
4. 결투 중 멈춤 → 설정 → 조작 → 처음 값으로 → 계속: 좌클릭 공격·W/S가 바로 돌아오는가. "계속"을 더블클릭해도 공격이 나가지 않는가.
5. 마음에 드는 키(예: 막기를 Shift나 옆 버튼)로 한 판: 쥐고 떼는 손맛이 마우스와 같은가.
6. 기다리는 동안 "돌아간다"나 "소리" 탭을 누르면 기다림만 취소되고 그 버튼이 눌리는가(키는 바뀌지 않는가). 알림 글로 좌클릭을 주는 법을 알 만한가.

S02의 직접 해 보실 넷(진짜 Alt+Tab, 우클릭을 쥔 채 Alt+Tab, X·Alt+F4, 손 더블클릭)도 아직 남아 있다.

## 3. 설계 문서와 다르게 구현한 부분과 이유

- 첫 확인에서 셋을 고쳤다:
  - T97의 "탭은 소리 하나" 기대가 낡았다.
  - T101-4는 테스트가 시간을 흘리지 않고 G를 눌러 막기 쿨다운에 걸렸다. 게임은 맞았다.
  - 장에서 조작 탭인데 "소리"가 눌려 보였다. 탭을 고르면 고른 하나만 눌리게 게임을 고쳤고 단언을 더했다.
- 고칠 때 하위 에이전트가 보고와 달리 한 줄(탭 목록에 담기)을 빠뜨려 메인이 넣었다.
- 대기 중 왼쪽 버튼을 버릴 때 "버린 공격" 수는 공격이 왼쪽에 묶였을 때만 센다(기본 묶음에서는 S02와 같다).
