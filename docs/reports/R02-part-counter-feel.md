3. 다리를 스친 뒤 다음 패리: "빈틈 +0.3초". "빈틈"을 "3일차부터"로 바꾸면 가끔 "다리가 풀려 틈이 열렸다".
4. "자유 결투 — 바르톨로"(반격 실험 켬): 큰 베기 뒤에만 "머리가 열렸다!". 패리만으로는 머리를 피한다.

## 3. 설계 문서와 다르게 구현한 부분과 이유

- 작업 5·6을 하위 에이전트 하나에 차례로 맡겼다(둘 다 작다).
- "베기만"은 패턴 줄이 아니라 자유 결투 줄(패턴 줄에 두면 폭 1216을 넘는다). 안내 글은 연습 화면의 한 줄이 아니라 버튼의 풍선말과 결투 도움말(한 줄 더하면 높이 738).
- 머리 "피한다"의 테스트 시각을 +0.25초 → +0.05초(+0.25초에는 "늦다"가 맞다).
- 이벤트의 새 칸은 효과가 일어났을 때만 싣고 `leg_time` 칸을 더했다(글의 "+0.3초"를 데이터에서 읽으려고).
- 효과 글("팔 둔함")을 오른쪽 위 판 아래로 내렸다(판과 겹쳤다).
- `partstats`는 9칸만 도는 인자(`-Nine`)를 더해 6줄로 맞췄다.
- 미리보기는 제한 시간이 판정보다 먼저 끝날 때도 띄우지 않는다.

## 4. 사용자가 결정해야 할 것 (판 P — 해 보신 뒤에)

- **P-1 조준 미리보기**: 가) 이대로 / 나) 조준 글의 덧말만 / 다) 뺀다
- **P-2 팔**(다음 3회 ×1.25. 막은 뒤 팔의 여유는 0.19초 — 새 규칙은 알려 줄 뿐 고치지 않는다): 가) 이대로(막은 뒤는 어렵고 패리 뒤에 노린다) / 나) 막은 뒤에도 팔이 닿게(값은 글로) / 다) 다른 효과 / 라) 뺀다
- **P-3 다리**(다음 패리의 덤, 예비 +0.10 — 막은 뒤 베기 하단이 0.09초가 됐다): 가) 이대로 / 나) 값을 바꾼다(글로) / 다) 시간 덤만 / 라) 뺀다
- **P-4 머리**(큰 공격 뒤 0.9초, 2칸. 패리 뒤에는 닫힌다): 가) 이대로 / 나) 패리 뒤에도 연다(지금의 규칙) / 다) 칸 수를 올린다(글로)
- **P-5 빨간 번쩍임 0.1초**: 가) 그대로 / 나) 줄이거나 테두리로(하루의 화면도 바뀐다 → R02b)
- **P-6 하루로 옮기기**: 가) R02b로 옮긴다 / 나) 연습에 더 둔다 / 다) 접는다
- 커밋: R02의 코드·문서와 계획 둘(R01·R02)을 아직 커밋하지 않았다.
