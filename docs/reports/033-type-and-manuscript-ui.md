## 3. 설계 문서와 다르게 구현한 부분과 이유

- **견본과의 차이를 고치는 차례**: 계획은 판 N 전에 메인이 차이를 두 번까지 고치고 다시 찍는 것이었다. 사용자가 "결과 나오면 스크린샷 보여줘"라고 해, 처음 찍은 장으로 판을 먼저 보였다. 남은 차이는 위 표의 끝 두 줄이고, 답과 함께 고친다.
- **문서(작업 8)**: playtester가 도는 동안 썼다.
- **T75**: 버튼은 코드가 놓은 크기의 표와 최소 크기를 견준다(기술 2회차 비차단). 상태 글자 두 줄의 높이는 INFO 줄이다(Godot이 잰 값 84, 바이블의 상자 80. 재는 법이 다르다).
- **정산의 장부 줄**: 견본의 22 대신 24(22는 단계 밖).
- **폐점**: 견본대로 나무 띠를 깔고 살 것 버튼의 글을 가운데로 맞췄다.
- **결의 세기**: Godot의 노이즈를 가운데 절반으로 좁혀 썼다(어림).
- **`pair-closing`**: 견본의 돌려보낸 손님(이네스)은 넣지 않았다. 정산·카운터·폐점의 점수는 고정 점수 의뢰에 실제 의뢰의 이름을 입혀 냈다.
