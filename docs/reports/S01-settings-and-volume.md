## 1. 한 일

- **설정 파일**(`scripts/settings.gd`, 자동 로드 `Settings`): `user://bravi_settings.json`. 영업 세이브와 파일·환경 변수·코드가 따로라 가게를 새로 시작하거나 세이브를 지워도 설정이 남는다. 모르는 칸은 지우지 않고(뒤의 S02~S04·글자 크기·고대비가 칸만 더하면 된다), 깨진 파일은 처음 값으로 읽는다.
- **설정 화면**(`scripts/ui/settings_screen.gd`): 탭 목록으로 짓고 지금은 "소리" 하나 — 음량 슬라이더(0~100, 5씩, 처음 값 100)와 "소리를 끈다/켠다", 끈 상태의 흐린 글 한 줄, "돌아간다"·Esc로 닫기. 그린 종이·테두리·버튼(033b)을 그대로 받는다.
- **막기 소리 미리 듣기**(`scripts/duel/beeper.gd`의 `play`): 슬라이더를 움직이면 막기 소리를 짧게. 끌 때 소리가 쌓이지 않게 120밀리초 안은 거르고, 놓을 때 거른 값이 있었으면 한 번 더. 음소거면 울리지 않는다. 화면을 열기만 해서는 울리지도 적히지도 않는다.
- **처음 화면**(`scripts/title.gd`): 도움말 자리를 "도움말 | 설정" 두 칸으로.
- **테스트·도구**: 새 T97(`tests/settings_tests.gd`), 러너와 찍기가 자동 로드의 쓰기를 끈다(`tests/run_tests.gd`, `tests/ui_shots.gd`), UI 찍기 16장(`settings` 장), 버튼 수 기대(`day_tests.gd`, `save_tests.gd`, `manuscript_tests.gd`의 T75가 설정 화면도 지난다).

## 2. 직접 실행해서 확인한 것 / 확인 못 한 것

**확인한 것**
- verifier: `VERIFY: OK`, `ALL PASS 97/97`(오류·경고 0), 스모크, 찍기 상대 57·UI 16·패턴 38, `fit select 1248x716` 그대로.
- T97: 설정과 영업 세이브가 섞이지 않는다(세이브에 `audio` 없음, 설정에 `day`·`money`·`owned` 없음), 새로 시작·세이브 지우기 뒤에도 설정이 남는다, 깨진 파일·범위 밖 값, 모르는 칸이 남는다, 버스에 음량·음소거가 걸린다, 열기만 하면 소리·파일 없음, 홈 한 번에 소리 한 번, 처음 화면에서 열고 Esc로 닫기.
- 실행 전후로 플레이어의 설정 파일(`bravi_settings.json`·`bravi_playtest_settings.json`)이 생기거나 바뀌지 않았다.
- 메인이 읽은 장: 처음 화면(두 칸), 설정 화면(`%TEMP%\bravi-S01\after2\ui\settings.png`).

**확인 못 한 것 — 소리는 직접 들어 봐 주세요**(창의 playtester는 소리를 듣지 못한다)
1. 처음 화면 → 설정 → 음량 슬라이더를 끌면 막기 소리가 짧게 나는가, 끌 때 소리가 쌓여 거슬리지 않는가.
2. "소리를 끈다"를 누른 뒤 슬라이더를 움직이면 소리가 나지 않는가.
3. 음량을 바꾸고 게임을 껐다 켜도 값이 남는가(가게를 새로 시작해도).
4. 결투의 소리(예비 동작·막기·패리)도 같이 줄어드는가.

## 3. 설계 문서와 다르게 구현한 부분과 이유

- 첫 확인에서 두 번 걸렸다: 테스트가 `AudioServer.is_bus_muted`(없는 이름 — `is_bus_mute`)를 불러 테스트 파일이 읽히지 않았고, 그 뒤 T75가 설정 화면의 글자 크기 22(아홉 단계 밖)를 잡았다 — 이름을 고치고 24로 바꿨다.
- 메인이 장에서 찾은 것: 설정 덮개 아래로 처음 화면의 안내 글이 비쳤다. 덮개가 화면 전체를 덮게 하는 설정을 붙이기 전에 두어 고쳤다.
- 설정 화면은 닫으면 지우고 다시 열면 새로 만든다(계획에 없던 세부 — 하위 에이전트가 정함).

## 4. 사용자가 결정해야 할 것

- 2번의 소리 넷을 들어 보시고 음량 곡선(50 = −6 dB, 임시)이 맞는지.
