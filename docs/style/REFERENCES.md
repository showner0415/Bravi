# 참고 자료 색인

참고 스크린샷은 `reference/`에 로컬로만 있고 저장소에 올라가지 않는다. 이 파일은 글로 된 색인이다(그림은 넣지 않는다). 지킬 선은 `reference/README.md`와 CLAUDE.md 7장에 있다.

## 말로 받은 방향 (사용자, 2026-11-21)

원문: "사람은 좋은 피자 위대한 피자처럼, 나머지는 potion craft처럼. 두 개의 게임을 섞은 느낌으로 게임 만들고 싶어."

- **인물**(의뢰인, 결투 상대, 결투 화면 아래의 내 손·칼): 「좋은 피자, 위대한 피자」처럼. 큰 머리, 단순한 얼굴, 굵고 깔끔한 윤곽선, 평평한 색, 표정으로 읽히는 성격.
- **배경·UI·질감·장식**: 「Potion Craft」처럼. 중세 필사본·판화풍의 잉크 선, 양피지, 바랜 색.
- 두 화풍을 잇는 방법(같은 색 범위, 인물 윤곽선의 잉크 질감 등)은 견본을 보고 고른다(계획 020).

계획 020의 견본은 참고 스크린샷 없이 이 말만 따랐다(사용자 답 2026-11-21: 자료는 계획 021에서 준다).

## 색인

계획 021에서 채운다.

| 파일 | 게임·장면 | 사용자 메모 | 본 성질 | 가져올 것 / 가져오지 않을 것 |
|---|---|---|---|---|

- **본 성질**: 말로 적는다. 선의 굵기(얼굴 폭에 대한 대략의 비)와 색, 머리:몸, 얼굴의 꼴(눈·입의 단순함), 칠의 단계 수, 질감의 종류, 색의 채도·명도 범위.
- **가져올 것 / 가져오지 않을 것**: 성질로만 적는다(인물·UI·글꼴을 옮기지 않는다).
