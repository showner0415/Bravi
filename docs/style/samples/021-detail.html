화풍 세부 견본 — 계획 021

보는 법: 020에서 고르신 다리 B와 짙은 무대, 지금 얼굴 크기로 그렸습니다. 결투 무대는 극장 대신 야외 셋(뒷골목·안뜰·광장)이고, 장면은 020의 결투와 같습니다(큰 베기의 예비 동작). 바르톨로와 의뢰인은 제가 SVG로 그린 것과 그림 생성(Codex)으로 만든 것을 나란히 둡니다. 생성 그림은 머리 104·팔 105로 맞춰 견줍니다. 상대의 자세·색·글자·고리는 지금 게임의 값 그대로입니다.

  1. 무대: 뒷골목 / 안뜰 / 광장. 그리고 SVG / 생성.
  2. 바르톨로의 기준: SVG / 생성 전신을 자른 것(G1) / 생성 파츠 시트(G2).
  3. 의뢰인의 기준: 사람마다 SVG / 생성.
  4. 4단계에서 그림을 만드는 길: 생성 + 파츠 시트 + 손질 / SVG / 섞기 / 사람이 그린다.
  5. 싫은 것이 있으면 한 줄로.

무대 · 뒷골목 — 큰 베기의 예비 동작(진행 0.25), 갓 올린 막기

왼쪽 가까운 집이 위층을 내밀고 그 밑에 쇠 간판이 걸린다. 오른쪽은 물러나는 집 벽 셋. 가운데는 골목 안쪽의 깊은 그늘과 좁은 밤하늘, 돌바닥이다. 상대 둘레·고리·두 줄 글자 자리에는 선이 없다.

무대 · 안뜰 — 같은 장면

왼쪽에 돌우물과 두레박, 담 너머로 넘어온 큰 나무. 오른쪽 뒤 벽에 큰 나무 대문 두 짝. 가운데는 그늘진 회벽과 판석 땅이다.

무대 · 광장 — 같은 장면

해 진 뒤 먼 집들의 지붕선과 종탑이 화면을 가로지른다. 왼쪽에 분수 가장자리, 오른쪽에 차양을 접은 장터 좌판과 나무 상자.

SVG 바르톨로 · 파츠 시트

결정 12의 파츠 여덟(머리는 표정 셋). 점은 그 파츠의 관절(원점)이다. 겹침 여유: 몸통의 목 밑동, 팔 윗끝의 둥근 머리, 주먹 밑까지 이어진 칼자루, 챙 밑까지 그린 머리.
