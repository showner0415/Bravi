글꼴 · UI · 크기 기준 — 계획 025

보는 법: 글꼴 후보와 UI의 꼴 세 안을 지금 게임의 자리와 글 그대로 놓았습니다. 글꼴은 이 컴퓨터의 로컬 파일(docs/style/generated/fonts/)로 읽습니다. 브라우저에 따라 로컬 글꼴을 막을 수 있어(Firefox 등) 판정은 구운 그림으로 합니다. 바탕·맑은 고딕 칸은 견줌용이고 게임에 넣어 배포할 수 없는 글꼴입니다. 주소에 ?ui=a|b|c, ?hudui=, ?body=, ?title=, ?state=, ?hud=serif|sans, ?warn=1을 붙여 바꿔 볼 수 있습니다.

  1. 본문 글꼴: font-body의 세 후보 가운데.
  2. 제목 글꼴: font-title의 세 후보 가운데.
  3. 결투 화면의 글자: font-state의 상태 글자, 그리고 HUD의 글자를 본문 글꼴로 둘지 고딕으로 둘지(ui-duel).
  4. UI의 꼴: 가(민 양피지) · 나(필사본) · 다(나무와 쇠). 엉킴·방심 막대의 짙은 띠는 세 안 공통이고, 고를 것은 그 둘레의 패널과 버튼의 꼴입니다.

본문 글꼴 — 나눔스퀘어라운드 ExtraBold(고른 것) · 고운바탕 · 나눔명조 · Noto Serif KR

제목 글꼴 후보 — 송명 · 함렛(굵게) · 본문과 같은 집안의 굵은 것

결투의 상태 글자 후보 — Noto Sans KR(900) · 검은고딕 · 도현 · (견줌) 맑은 고딕
