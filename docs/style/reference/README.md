# 참고 스크린샷

화풍을 정할 때 참고하는 다른 게임의 스크린샷(「좋은 피자, 위대한 피자」, 「Potion Craft」)을 이 폴더에 넣는다.

- **이 폴더의 그림은 저장소에 올라가지 않는다**(`.gitignore`). 상용 게임의 이미지라서다. 다른 컴퓨터에서 이어 받으면 그림은 따로 옮긴다.
- 파일 이름: `<게임>-<번호>-<장면>`. 예: `pizza-01-counter.png`, `potion-01-shop.png`.
- 메모(좋은 점·싫은 점)는 `../REFERENCES.md`의 색인에 적는다.

## 참고 자료의 선 (계획 020, 결정 179)

1. 참고 이미지를 따라 그리거나, 겹쳐 놓고 그리거나, 잘라 쓰지 않는다. 견본은 우리 게임의 장면을 새로 그린 것이다.
2. 두 게임의 인물·의상·로고·UI 틀·아이콘·글꼴을 옮기지 않는다. 가져오는 것은 말로 적을 수 있는 성질뿐이다(선의 굵기와 색, 머리와 몸의 비, 칠의 단계 수, 질감의 종류, 색의 채도·명도 범위).
3. 이미지 생성에 참고 스크린샷을 이미지 입력으로 넣지 않는다. 프롬프트에 두 게임·제작사·작가의 이름을 쓰지 않는다.
4. 참고 스크린샷을 저장소 밖(Artifact 등)에 올리지 않는다.
