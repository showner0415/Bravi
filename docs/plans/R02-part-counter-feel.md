## 목표와 범위

연습 화면에 "반격 실험: 옛 규칙 / 새 규칙" 고르기가 생기고, 새 규칙에서 (가) 조준 미리보기가 뜨고 (나) 팔·다리·머리의 스침이 다음 공방을 바꾼다. 사용자가 같은 상대로 둘을 오가며 견주고 수치를 정한다.

**확인할 결과**

1. 부위별 "가장 늦게 눌러도 닿는 시각"의 표가 실제 코어를 돌린 수로 나왔고, 1절의 셈과 같다.
2. 새 규칙에서 조준 미리보기의 말(닿는다 / 늦다 / 멀다 / 피한다)이 그 순간 누른 공격의 판정과 언제나 같다. 미리 알 수 없는 때(D2의 표에 적힌 둘뿐)에는 아무 말도 하지 않는다(T105).
3. 새 규칙에서 팔·다리·머리의 스침이 U3대로 움직이고, 값은 `data/part_effects.tres` 한 파일에서 바뀐다.
4. 옛 규칙(상대의 `part_effects`가 비어 있음)에서는 판정·난수 차례·화면이 지금과 같다: 기존 T001~T103이 고치지 않고 통과한다.
5. 의뢰의 채점이 새 규칙을 켠 상대에서도 같다(T110).
6. 재현 세 장면(몸통 / 팔 / 너무 늦음)의 그림과 수가 남고, 보고서에 연습 메뉴의 길이 적혔다.

**범위 밖**

- 하루의 결투: `data/opponents/*.tres`에 `part_effects`를 적지 않는다(비어 있으면 꺼짐). 하루로 옮기는 것은 사용자 판정 뒤의 다음 계획(R02b)이다.
- 연습 화면의 의뢰 카드(의뢰 연습)는 옛 규칙 그대로다. 새 규칙은 "자유 결투"·"패턴만"·"베기만" 버튼에만 탄다. 의뢰와의 충돌은 테스트(T110)로 본다.
- 몸통의 예비 시간, 무기 데이터(`rapier.tres`), 상대의 회수 시간·스침 칸 수(`opponent_0N.tres`)는 고치지 않는다. 타격 순간의 빨간 번쩍임(0.1초)도 그대로 둔다(1절 F7, 판 P-5로 묻는다).
- 그림·소리 애셋을 새로 만들지 않는다(표시는 선·도형·글과 기존 파츠의 색).

### "팔·머리는 늦다"의 원인

가장 늦게 눌러도 닿는 시각 = 빈틈의 길이 − 내 예비 시간(F1·F3). 바르톨로, 교전, 단발 베기 기준의 셈(작업 1이 실제 코어로 다시 잰다):

| 부위 | 조준 | 예비 | 막은 뒤(빈틈 0.55) | 패리 뒤(1.40) |
|---|---|---|---|---|
| 몸통 | 찌르기 중단 | 0.20 | **0.35 미만** | 1.20 미만 |
| 몸통 | 반대쪽 베기 중단 | 0.35 | 0.20 미만 | 1.05 미만 |
| 팔 | 칼 쪽 베기 중단 | 0.35 | **0.20 미만** | 1.05 미만 |
| 다리 | 찌르기 하단 | 0.20 | 0.35 미만 | 1.20 미만 |
| 다리 | 베기 하단 | 0.35 | 0.20 미만 | 1.05 미만 |
| 머리 | 찌르기 상단 | 0.40 | 0.15 미만이지만 **피함** | 1.00 미만 |
| 머리 | 반대쪽 베기 상단 | 0.70 | 닿을 수 없음(−0.15) | 0.70 미만 |
| 손 | 칼 쪽 베기 상단 | 0.70 | 닿을 수 없음 | 0.70 미만 |

1. **팔은 베기로만 닿는다.** 몸통은 찌르기(0.20)로 닿아 막은 뒤 0.35초의 여유가 있는데, 팔은 베기(0.35)라 0.20초뿐이다. 빨간 번쩍임 0.1초(F7)를 빼면 파란색을 보고 누를 수 있는 시간이 몸통 0.25초, 팔 0.10초다. 사람의 반응(0.2~0.3초)으로 몸통은 되고 팔은 안 된다.
2. **머리는 상단 배율 ×2.0**(0.40 / 0.70)에 더해, 막기만 한 빈틈에서는 닿아도 피한다(F6). 그런데 몸은 파랗다.
3. **파란색은 "상대가 빈틈이다"만 말하고 "내 이 조준이 닿는다"를 말하지 않는다**(F7·F9). 늦었는지는 칼이 나간 뒤에야 "닿지 않음"으로 안다(F5).
4. 다리는 찌르기 하단으로 몸통과 같은 0.20초다. 지금 표에서 다리와 몸통은 차이가 없다(2절 D5가 다룬다).

## 2. 설계 결정

수치는 전부 임시다(사용자가 해 보고 정한다). 되돌리기: `OpponentData.part_effects`를 비우면 전부 꺼진다.

**D1. 켜고 끄는 자리 — 상대 데이터의 `part_effects`(새 Resource `PartEffectData`).** 비어 있으면 옛 규칙이다. 값은 `data/part_effects.tres` 한 파일에 있고 연습 화면이 사본에 실어 준다(`OpponentData.with_part_effects(fx)`, `with_opening`과 같은 꼴). 하루의 상대 `.tres`에는 적지 않는다. 낱낱의 효과는 그 값을 0으로 두면 꺼진다(미리보기는 `show_forecast`).

**D2. 미리보기와 판정은 한 함수.** `DuelCore`에 순수 함수 하나(`_verdict(part, lunge, judge_time, judge_distance) -> DuelTypes.Forecast`)를 두고 `_judge_attack`과 새 `attack_forecast()`가 함께 부른다. `attack_forecast()`는 "지금 누르면"의 판정 시각(`time + attack_windup()`)과 그때의 간격을 넣는다. 머리가 열렸는지는 `head_open_at(t)` 하나가 답하고 판정·미리보기·런지의 글(`lunge_head_dodged_now`)·상대 그림의 머리 색이 모두 그것을 읽는다. 내 예비 시간도 `attack_windup(direction, height)` 하나로 `press_attack`과 미리보기가 함께 쓴다.

`Forecast`의 값: `UNSURE`(미리 알 수 없다 — 아무것도 그리지 않고 덧말도 없다) / `NO_OPENING`(빈틈이 아님 — 지금처럼 아무것도 더 그리지 않는다) / `REACH` / `OUT_OF_RANGE` / `LATE` / `HEAD_GUARDED` / `BIND_CUT`(예비 중에 엉킴이 다 차 공격이 끊긴다). `attack_forecast()`는 `{verdict, margin}`을 돌려준다(`margin` = 빈틈의 끝 − 판정 시각. `REACH`에서 "얼마나 더 기다려도 되는가").

**D2-1. 누른 시각과 판정 시각 사이의 예정된 전이(T1).** `attack_forecast()`는 지금의 상태가 아니라 **판정 시각의 상태**를 `_foresee(judge_time, lunge)`로 미리 셈해 `_verdict`에 넣는다. `_foresee`는 난수와 내 다음 입력 없이 정해지는 것만 셈하고, 나머지는 `UNSURE`다. `_judge_attack`은 같은 `_verdict`에 실제 값을 넣는다. 같은 시각의 차례는 코어의 `_Ev` 순서를 따른다(상대 → 접근 → 나 → 엉킴: 상대의 전이가 판정 시각과 같으면 먼저 일어난 것으로, 엉킴이 같으면 판정이 먼저다).

| 누른 순간 | 판정 시각 전에 예정된 것 | 미리 셈한 판정 시각의 상태 → 값 |
|---|---|---|
| 누를 수 없다(끝남, 내 상태가 READY·GUARD가 아님: 예비·회수·걸음·밀려남. `press_attack`의 조건) | — | `UNSURE` |
| 회수·무너짐 | 그 끝(`state_end` ≤ 판정 시각) | 대기 → 보통 공격은 `LATE`, 런지는 대기의 런지로 셈(`REACH`·`HEAD_GUARDED`. 런지에는 `LATE`가 없다) |
| 회수·무너짐 | 없음 | 그 상태 그대로 → `REACH`·`HEAD_GUARDED`(`head_open_at(판정 시각)`) |
| 예비 동작 | **상대의 타격**(`state_end` ≤ 판정 시각) | `UNSURE`. 타격의 결과(헛침·뛰어들기의 간격 이동·사슬·빈틈)를 따로 셈하지 않는다. 뛰어드는 찌르기를 멀리로 피하고 타격 전에 누른 공격이 여기다 |
| 예비 동작 | 없음 | 예비 동작 그대로 → 멀리면 `OUT_OF_RANGE`(런지는 `NO_OPENING`), 아니면 `NO_OPENING` |
| 대기, 멀리 | **접근**(`_approach_at` ≤ 판정 시각) | 간격 = 교전. 접근 때 새로 뽑는 대기가 판정 전에 끝날 수 없으면(`_approach_at + idle_time_min` > 판정 시각) 대기 → 보통 공격 `NO_OPENING`, 런지 `REACH`·`HEAD_GUARDED`. 끝날 수 있으면 `UNSURE` |
| 대기, 멀리 | 없음 | 보통 공격 `OUT_OF_RANGE`, 런지 `REACH`·`HEAD_GUARDED` |
| 대기, 교전·밀착 | 대기의 끝(예비 동작이 시작된다) | 어느 쪽이든 빈틈이 아니다 → `NO_OPENING` |
| 밀착(어느 상태든) | 엉킴이 다 참: `_bind_full_at` < 판정 시각. 또는 **무너짐이 판정 전에 끝나 게이지가 다시 차는 경우**: 무너짐의 끝 + (1 − 지금 게이지) × `close_bind_time` < 판정 시각 | `BIND_CUT`(다른 값보다 먼저 본다) |

`UNSURE`가 나오는 때는 위의 셋뿐이다(누를 수 없음, 예비 동작 중 타격이 먼저 옴, 접근 뒤 대기가 끝날 수 있음). **빈틈(회수·무너짐) 동안에 누를 수 있으면 `UNSURE`는 나오지 않는다**(T105가 본다). 사용자가 바란 "파란색을 보고 한 판단"은 늘 답을 받는다.

**D3. 미리보기의 꼴 — 색만이 아니라 꼴과 글(원칙 4).** 빈틈(회수·무너짐) 동안과 멀리에서만 뜬다. 타격 순간의 빨간 번쩍임 동안에도 뜬다(막은 순간부터 읽힌다). 세 자리에 같은 말을 쓴다.

| 판정 | 조준 칸의 테두리(`duel_scene._draw`) | 부위 곁의 꼬리표(`OpponentView`, 윤곽선 옆) | 조준 글의 덧말(`DuelHud`) |
|---|---|---|---|
| 닿는다 | 굵은 실선 | "닿는다" + 줄어드는 여유 막대(`margin`) | "(닿는다)" |
| 늦다 | 끊긴 선(점선) | "늦다" + 빈 막대 | "(늦다 — 칼이 닿기 전에 빈틈이 끝난다)" |
| 멀다 | 네 모서리의 꺾쇠만 | "멀다" | 지금의 "(멀리: 닿지 않음)" |
| 피한다 | 실선 + 가위표 | "피한다" | "(머리를 지킨다 — 피한다)" |
| 엉킴 | 끊긴 선 | "엉킴" | "(엉킴 — 공격이 끊긴다)" |

꼬리표는 상태 글자("빈틈")·번호 고리·HUD의 판과 겹치지 않는 자리에 둔다(작업 3의 찍기로 본다). 흑백으로 바꿔도 다섯이 꼴로 갈려야 한다. `UNSURE`와 `NO_OPENING`에서는 셋 다 지금 화면 그대로다(새 규칙의 멀리에서 "(멀리: 닿지 않음)"은 `OUT_OF_RANGE`일 때만 뜬다). 런지의 조준 글(`lunge_aim_note`)은 글을 그대로 두고 `attack_forecast()`를 읽게만 바꾼다(`UNSURE`면 덧말 없음. 옛 규칙의 판에서는 지금의 함수 그대로다).

**D4. 팔 — 다음 3회의 예비 동작이 길어진다.** 칼 든 팔을 스치면(`GRAZE`, 런지 포함) `OpponentBrain.slow_tells_left = arm_slow_tells`(3). 다시 스치면 3으로 되돌린다(쌓지 않는다). 예비 동작을 시작할 때 1을 쓰고 그 공격의 모든 타격 간격(뿌리의 예비와 사슬의 간격)에 `arm_tell_multiplier`(1.25)를 곱한다. 패턴 하나가 1회다. 난수를 부르지 않는다. 번호 고리의 시각(`pattern_strike_times`)도 같은 배율을 쓴다. 보이는 것: 상대 자세 칸 아래의 "팔 둔함 ●●●"(남은 횟수), 느려진 예비 동작의 상태 글자 끝 "(둔함)", 그동안 칼 든 팔 파츠의 잿빛 물(기존 색 셰이더). 스친 순간의 글 "스침 — 칼 든 팔 (-2) · 다음 공격 3번이 느려진다". 칼 든 손은 이번에 효과가 없다(막은 빈틈에서 닿지 않는 자리라 표로만 보인다).

**D5. 다리 — 다음 패리 성공의 덤. 그리고 다리 조준의 예비 +0.10초.** 다리를 스치면 `parry_charges = legs_parry_charges`(1). 다음에 **패리로 끝난** 공격에서 한 번 쓴다. 패리 창(`parry_window`)·막기 판정은 건드리지 않는다(쉬워지는 것은 패리가 아니라 패리 뒤다). 막힘으로 끝난 공격과 사슬 중간의 패리는 쓰지 않고 남는다. 굴림 값은 예비 동작 때 이미 뽑혀 있어 난수 차례는 그대로다.

패리에는 이미 덤 +0.25가 있어(`opponent_brain.gd:162`, `duel_rules.gd:21`) 확률의 덤만으로는 거의 달라지지 않는다. 바르톨로(0.80)의 패리 뒤 빈틈 확률:

| 연습의 빈틈 | 판의 확률 | 패리 뒤, 다리 덤 없음 | 확률 덤 +0.30만 줄 때 | 덤이 실제로 뒤집는 굴림 |
|---|---|---|---|---|
| 늘 열린다 | 1.00 | 늘 열림 | 늘 열림 | 0% |
| 1일차 | 0.80 | 1.05 → 늘 열림 | 늘 열림 | 0% |
| 2일차 | 0.72 | 0.97 | 늘 열림 | 3% |
| 3일차부터 | 0.64 | 0.89 | 늘 열림 | 11% |

그래서 **덤은 쓰일 때마다 반드시 한 가지 눈에 보이는 일을 한다**(사용자의 "늘 열리는 규칙에서는 열린 시간"을 "덤 없이도 열렸을 패리"까지 넓힌 것이다):

1. 덤 없이는 안 열렸을 굴림(`opening_roll` ≥ 확률 + 패리 덤)이고 `legs_parry_opening_bonus`(+0.30)를 더하면 열린다 → **열린다**. 글 "패리! — 다리가 풀려 틈이 열렸다". 시간은 더하지 않는다.
2. 덤 없이도 열렸을 패리(확률이 1.0인 판 포함) → 그 회수에 `legs_open_time_bonus`(**+0.30초**). 글 "패리! — 다리가 풀려 빈틈 +0.3초".
3. 덤을 더해도 안 열리는 굴림(지금 값에서는 없다. 값을 낮추면 생긴다) → 안 열리고 덤은 쓰인다. 글은 지금의 "틈을 안 준다" 그대로(덤이 한 일이 없으니 말하지 않는다).

모든 빈틈 설정에서 다리 덤이 쓰인 패리는 덤 없는 같은 패리와 다르다: 열리지 않았을 것이 열리거나, 0.30초 더 열린다. `STRIKE` 이벤트의 `leg_bonus`는 `&"opened"` / `&"time"` / `&"none"`(3번) / `&""`(덤 없음)이고 글은 그 값만 읽는다. 보이는 것: "다리 흔들림 ◆ 다음 패리".
다리는 찌르기 하단으로 몸통과 같은 0.20초라(1절 4번) 덤만 붙이면 몸통을 고를 까닭이 없어진다(U3 "몸통은 덤 없이도 고를 이유"). 그래서 새 규칙에서는 부위마다 예비에 더하는 값을 데이터에 둔다: `legs_windup_extra` 0.10, `arm_windup_extra`·`head_windup_extra`·`hand_windup_extra` 0. **몸통의 칸은 만들지 않는다**(U1. T104가 몸통의 예비가 옛·새 규칙에서 같음을 본다). 이 칸들이 U1의 "실제 판정값을 보고 조정"의 손잡이다. 음수도 받는다(예: `arm_windup_extra` −0.15면 막은 뒤의 팔이 몸통만큼 닿는다). 더한 뒤의 예비는 0.05초 아래로 내려가지 않는다. 다리는 0.10초 느려지는 대신 덤이 쓰일 때마다 위의 1·2 가운데 하나가 반드시 보이므로 "느려지기만 하는 부위"가 되지 않는다.

**D6. 머리 — 큰 공격 뒤에만, 짧게, 뚜렷하게.** 새 규칙에서 머리는 **뿌리가 큰 공격인 회수**(큰 베기·세 번 베기)에서만 열린다(`head_big_only` 참. 패리만으로는 열리지 않는다). 그 회수가 시작되고 `head_exposed_time`(0.9초) 안에 판정 시각이 들어야 닿는다(0이면 회수 내내). 무너짐은 지금처럼 늘 닿는다. 표시는 흐리게 하지 않는다: 열린 동안 머리에 파란 물이 들고 상태 글자가 "머리가 열렸다!"이며(지금의 "크게 열림!" 자리), 시간이 지나면 머리의 물만 빠지고 글자가 "빈틈"으로 돌아간다. 미리보기는 그 뒤 "피한다"다. 보상은 기존 값 그대로다: 머리 스침 2칸(F8. 자세 9의 22%, 몸통의 두 배이고 "스침 — 머리 (-2)"와 자세 칸으로 바로 보인다). 덤 효과는 붙이지 않는다. 회수의 길이(패리의 +0.85)는 바꾸지 않는다.

**D7. 채점과 기록.** 효과는 `ATTACK`·`STRIKE`·`TELL_START` 이벤트에 칸을 **더하기만** 한다(`effect`, `slowed`·`slow_left`, `leg_bonus`). 있던 칸의 값은 바꾸지 않는다(F11). 모자는 머리와 다른 부위라 D6의 규칙이 걸리지 않고 효과도 없다. 유효타(`HIT`)는 효과를 주지 않는다.

**D8. 연습 화면.** 제목 줄의 "빈틈" 버튼들 옆에 켜고 끄는 버튼 하나 "반격 실험"(눌리면 새 규칙. 기본은 꺼짐, `static`이라 결투에서 돌아와도 남는다). 첫 상대(바르톨로)의 "패턴만" 줄 앞에 "베기만" 버튼 하나(단발 베기 하나만 되풀이. F10). 막는 법의 글에 한 줄을 더한다. 720 안에 드는지는 UI 찍기로 본다.

## 6. 사용자 결정 필요

**검토 전에 정할 것: 없다.** 수치는 사용자가 해 보고 정한다고 했으므로 전부 임시 값으로 정했다(2절). 방향이 갈릴 수 있는 셋은 사용자의 말에 가장 가까운 쪽으로 정하고 데이터로 되돌릴 수 있게 했다: 머리는 큰 공격 뒤에만(D6, `head_big_only`), 다리 조준의 예비 +0.10초(D5, `legs_windup_extra`), 의뢰 연습은 옛 규칙(범위 밖).

**해 본 뒤에 물을 것 — 판 P**(보고서와 함께. 선택 창으로 물을 수 있는 꼴. 수치는 글로 받는다)

| 문항 | 선택지 | 답에 따라 달라지는 것 |
|---|---|---|
| P-1 조준 미리보기 | 가) 이대로 좋다(추천) / 나) 조준 글의 덧말만 남긴다 / 다) 뺀다 | 가: R02b에서 하루에도 켠다. 나·다: 꼬리표·칸 테두리를 지운다 |
| P-2 팔(다음 3회 느려짐). 보고서에 작업 1의 수를 나란히 싣는다: 막은 뒤 팔 0.20초(번쩍임을 빼면 0.10초), 몸통 0.35초(0.25초). 새 규칙은 이것을 알려 줄 뿐 고치지 않는다 | 가) 이대로 — 막은 뒤의 팔은 어렵고 패리 뒤에 노린다(추천) / 나) 막은 뒤에도 팔이 닿게 한다(`arm_windup_extra`를 음수로, 값은 글로) / 다) 효과의 값을 바꾼다(글로) / 라) 뺀다 | 전부 `part_effects.tres`의 값만. 나는 R2(팔이 몸통을 지배)를 키우므로 칸 수·횟수와 함께 본다 |
| P-3 다리(다음 패리의 덤: 덤이 뒤집으면 열리고 아니면 +0.3초. 예비 +0.10). 보고서에 D5의 표를 싣는다 | 가) 이대로(추천) / 나) 값을 바꾼다(글로) / 다) 시간 덤만 쓴다 / 라) 뺀다 | 값은 `part_effects.tres`만. 다는 `legs_parry_opening_bonus` 0 |
| P-4 머리(큰 공격 뒤 0.9초, 2칸) | 가) 이대로(추천) / 나) 패리 뒤에도 연다(지금의 규칙) / 다) 칸 수를 올린다(글로) | 나: `head_big_only` 거짓. 다: 상대 데이터의 `graze_head` |
| P-5 타격 순간의 빨간 번쩍임(0.1초가 파란색을 덮는다. 1절 F7) | 가) 그대로(추천 — 미리보기가 그동안에도 뜬다) / 나) 줄이거나 테두리로 바꾼다 | 나: 하루의 화면도 바뀌므로 R02b에 넣는다 |
| P-6 하루로 옮기기 | 가) R02b로 옮긴다 / 나) 연습에 더 둔다 / 다) 접는다 | 가: 하루의 상대 셋에 `part_effects`를 걸고 의뢰·통계를 다시 본다 |
