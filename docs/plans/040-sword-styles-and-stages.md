## 목표와 범위

지금의 세 상대가 **기본 검술과 고유 검술**을 데이터로 갖고, 날이 가면 그 검술이 제 결대로 **단**을 하나씩 올린다. 연습 화면에서 단을 골라 익히고, 봇 통계로 "조금씩 어려워진다"와 한계를 잰다.

**확인할 결과**:

1. 고유 검술마다 이름과 제 색이 있고(이어 베기 청록 · 휩쓸기 포도주빛 · 뛰어드는 찌르기 자홍), 기본 검술의 색과 몸의 상태 색·초록에서 떨어져 있다(T114, 찍기 V3).
2. 단은 데이터다: 상대의 `.tres`에 단을 더하면 코드 없이 그날부터 그 공격으로 싸운다. 단의 수에 코드의 상한이 없다(T112). 저장은 그대로다(T115).
3. 하루에서 4·5·6·7일차에 바르톨로·브루노가 한 단씩 오르고(기본과 고유가 번갈아), 1주차 뒤 9·11일차에 한 단씩 더 오른 뒤 머문다. 1~3일차의 판정은 지금과 같다(T115, 기존 111개).
4. 모든 단이 원칙 4의 한계 안이다: 타격 사이 0.55초 이상, 한 패턴 4타·3.5초까지, 예비 동작은 짧아지지 않는다, 막은 뒤의 빈틈은 0이거나 0.55초 이상이다(T113).
5. **단이 오르면 조금씩 어려워지고 쉬워지지 않는다**: 틀리는 봇의 판당 맞음과 승 수, 틀리지 않는 봇의 판 길이와 빈틈 수(V2, 결정 593).
6. 연습 화면에서 단을 골라 자유 결투와 "패턴만"으로 익힌다. 화면은 1248×720 안(T115, V1).

## 설계 결정

579. **단(tier)은 "공격 목록을 바꾼 사본"이다**. 새 Resource `StyleTier`(`scripts/ai/style_tier.gd`): `from_day: int`(이 날부터), `attacks: Array[AttackData]`(그 단의 일반 공격 전부 — 기본과 고유를 함께 적는다). `OpponentData.tiers: Array[StyleTier]`는 **2단부터** 담는다. 1단은 지금의 `attacks`다. 단의 수는 배열의 길이이고 코드에 상한이 없다.
     - `tier_for_day(day) -> int`: `from_day <= day`인 마지막 단의 번호(1단이 0). `day <= 0`이거나 맞는 단이 없으면 0.
     - `at_tier(index) -> OpponentData`: 0이면 **자기 자신을 그대로** 돌려준다. 1 이상이면 `duplicate()`한 사본에 `copy.attacks = tiers[i].attacks`를 **새로 대입**한다(원본과 단 데이터의 배열을 고치지 않는다. 번호가 넘치면 마지막 단). `for_day(day)`는 둘을 이은 것, `tier_count()`는 1 + `tiers.size()`.
     - 버릇·자세·리듬·빈틈의 확률·그림은 단과 상관없이 원본 그대로다(결정 425가 단에도 선다).
     - 까닭: 뇌와 코어를 고치지 않고, 1단인 판은 객체까지 같아 난수의 차례와 기존 테스트가 그대로다. 되돌리기 쉽다(`tiers`를 비우면 꺼진다).
580. **진화를 끈 사본은 따로 만들지 않는다**: 진화는 `for_day`·`at_tier`를 부른 곳에서만 일어난다. 원본을 직접 읽는 테스트와 `Plain.of`는 그대로 1단을 본다. 지금 4일차 넘는 하루 모드 씬을 도는 테스트는 없으므로 고칠 기대가 없다. `DuelScene.style_tier := -1`(−1이면 날을 따르고 0 이상이면 그 단으로 고정)은 T115와 뒤의 일정 계획(039의 049)이 쓰는 훅으로 둔다.
581. **갈래의 표시**: `AttackData.signature := false`(참이면 고유 검술의 공격. 뿌리와 변주에 적는다 — 걸음은 뿌리를 따른다), `OpponentData.style_name := ""`. 값: 바르톨로 "이어 베기", 브루노 "휩쓸기", 로렌초 "뛰어드는 찌르기". 기본 검술은 `signature`가 거짓인 것 전부다.
582. **고유 색**(메인이 대신 고름 — 사용자 위임. 임시, `.tres`의 값):
     - 이어 베기·세 번 베기·네 번 베기 **청록 (0.1, 0.85, 0.85)**, 휩쓸기·되돌려 휩쓸기 **포도주빛 (0.62, 0.12, 0.5)**, 뛰어드는 찌르기 자홍 (1, 0.45, 0.8) 그대로.
     - 고른 기준(T114가 잰다): 몸의 상태 색 다섯(빨강·파랑·무너짐 보라·흰색·잿빛), 초록 셋, 기본 색 셋(노랑·호박·주황)에서 RGB 거리 0.35 이상, 고유 색끼리 0.25 이상. v1의 연두는 초록("좋다")과, 보라는 무너짐의 보라와 겹쳐 버렸다. 청록은 파랑에서 0.42, 초록에서 0.43~0.46이고 포도주빛은 빨강에서 0.45, 무너짐 보라에서 0.42다(손 계산). 자홍은 무너짐 보라에서 0.37이라 문턱을 0.35로 둔다.
     - 색의 자리가 좁다(따뜻한 띠·초록·파랑·보라·흰색이 다 쓰였다). 한 판에는 한 상대뿐이니 **판 안에서 갈려야 하는 것**(그 상대의 기본과 고유, 상태 색)을 먼저 지키고 상대끼리는 느슨하게 둔다. V3의 장에서 청록이 빈틈의 파랑(또는 초록)과 이어져 읽히면 **파랑~초록 호 밖의 색**으로 바꾼다(남색은 빈틈의 파랑과 색상이 같아 쓰지 않는다. 문턱을 넘는 값을 T114로 골라 값만 고친다 — 후보: 연분홍 쪽). 포도주빛이 타격의 빨강과 이어져 읽히면 빨강에서 더 먼 쪽(자주)으로 민다. 특히 **사슬 중간**을 본다: 걸음을 막은 직후 몸이 다시 청록으로 돌아오는 순간이 "열렸다"(파랑)로 읽히면 안 된다.
     - **걸음의 사본**: 뷰가 걸음의 색을 쓰므로 고유 패턴의 걸음은 제 색을 가진 사본이어야 한다. 바르톨로는 청록 사본 셋(`step_cut_left`·`step_cut_right`·`step_thrust` — 방향·간격·높이 배열·포즈는 원본과 같고 색만 다르다)을 만들고 1단 패턴의 `chain`도 그것을 가리키게 한다. 브루노의 걸음은 색만 바꾼다. 로렌초의 "한 번 더"의 걸음은 자홍 사본이다. 그래서 "1단 불변"은 **`attacks` 줄, 판정 값, 높이 배열이 같다**는 뜻이다(색만 다르다. 높이 배열이 같아 난수의 차례도 같다).

     - **겹찌르기** — 찌르기 → 찌르기(간격 0.65). 예비 0.75, **막아도 빈틈 0**(단발 찌르기와 같다 — 끝이 찌르기면 틈이 없다. 마지막을 패리하면 지금 규칙대로 0.85가 열린다), 가중치 1.
     - **찌르고 베기** — 찌르기 → 왼쪽 베기(변주: 오른쪽 베기), 간격 0.75. 예비 0.75, 다 막으면 빈틈 0.55(끝이 베기면 단발 베기와 같은 틈), 가중치 1.
     - 단발 찌르기·베기의 값은 어느 단에서도 그대로다.
585. **바르톨로 — 이어 베기의 결: 좌우를 번갈아, 타수가 는다**:
     - 2단: 이어 베기(2타)에 **같은 쪽 두 번**의 길 둘(우→우, 좌→좌. 높이가 타격마다 뽑혀 위아래가 갈린다) — 네 길.
     - 4단: 이어 베기가 **3타**(우→좌→우, 좌→우→좌, 우→우→좌, 좌→좌→우). 빈틈 1.2 → 1.4. 길이 2.4초.
     - 6단: 세 번 베기의 자리에 **네 번 베기**(우→좌→우→찌, 좌→우→좌→찌. 큰 공격, 예비 0.9, 빈틈 1.8, 길이 3.05초).
     - 7단: 네 번 베기에 **찌르기가 사이에 끼는** 길 둘(우→좌→찌→우, 좌→우→찌→좌. 길이 3.05초) — 네 길.
586. **브루노 — 휩쓸기의 결: 쥐고 끄는 한 줄, 점이 늘고 길이 꺾인다**(점 사이 0.6초, 예비 1.0, 빈틈 1.6 그대로. 이웃한 칸으로만 간다. 4점 길의 빈틈은 1.8, 길이 2.8초):
     - 2단: **꺾이는 4점** — 휩쓸기에 (왼 중 → 가운데 중 → 오른 중 → 오른 하), 되돌려 휩쓸기에 (오른 중 → 가운데 중 → 왼 중 → 왼 상).
     - 4단: **계단 4점** — (왼 상 → 가운데 상 → 가운데 중 → 오른 중), (오른 하 → 가운데 하 → 가운데 중 → 왼 중). 가운데에서 세로로 끄는 걸음이 처음 나온다.
     - 6단: **세로 3점** — 휩쓸기에 (가운데 상 → 중 → 하), 되돌려 휩쓸기에 (가운데 하 → 중 → 상). 가로로 끌지 않는 길이 처음 나온다.
     - 7단: **되짚는 4점** — (왼 중 → 가운데 중 → 오른 중 → 가운데 중), (오른 중 → 가운데 중 → 왼 중 → 가운데 중). 끌던 쪽으로 되돌아온다.
587. **로렌초 — 뛰어드는 찌르기의 결: 물러섰다 뛰어든다, 닿은 뒤에 한 번 더**:
     - 2단: 높이가 중·하에서 **상·중·하**로.

     - 6단: "한 번 더"의 둘째가 **베기**인 길 둘(뛰어들기 → 왼쪽 베기 / 오른쪽 베기, 간격 0.75, 회수 2.0).
